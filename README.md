# Introducción a C Workshop 2026-II

Este workshop ofrece una introducción práctica al lenguaje C, desde la ejecución de programas en la línea de comandos hasta el manejo de memoria y archivos. Los contenidos combinan fundamentos, guías y ejercicios para fortalecer la lógica de programación y la resolución de problemas.

## Contenidos

| Módulo | Temas |
| --- | --- |
| [Línea de comandos](0_linea_comandos/) | Compilación y ejecución de programas en C. |
| [Control de flujo](1_control_de_flujo/) | Condicionales, ciclos y toma de decisiones. |
| [Funciones](2_funciones/) | Modularización, parámetros y argumentos de `main`. |
| [Punteros](3_punteros/) | Direcciones de memoria y manipulación de datos. |
| [Memoria dinámica](4_memoria_dinamica/) | Uso de memoria dinámica, vectores y matrices. |
| [Archivos](5_archivos/) | Lectura, escritura y manejo de archivos. |
| [Estructuras](6_estructuras/) | Organización de datos con `struct`. |
| [Ejercicios propuestos](ejercicios_propuestos/) y [prueba final](prueba_final/) | Aplicación de los contenidos del workshop. |
